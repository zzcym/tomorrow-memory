## 2. §5.4-4 定稿一句话（供 T-03 / T-09 / T-13 / T-16 与 UI 下一轮直接引用）

> **本期用户可见面上的"字符上限"只有一个数值：单词本词条词名 ≤ 64 个字符；超限时用户看到的仍是 §5.4-2 那句「这个词没法存进单词本（词名不能为空，最长 N 个字符）」（N 由常量模板组装、句内数字 = 64），错误码仍是 400 `INVALID_WORDBOOK_ENTRY`；搜索/查词输入本期不设字符上限、不设错误码、不新增任何文案。**

- **搜索面为什么"不设限"而不是"没定"**：① 词本搜索是本地子串过滤、**不发请求**（R-15③ / UI §3.6.3），超限后果只是"没有匹配"，已由既有空态「没有符合条件的词」承接；② 查词口 `/api/lookup` 在 §6.2 的**不得下线/改形**清单里，输入侧加 `maxLength` 等于改变已发布面的形状；③ 为它单开一条码违反 A-28-4"域内不得再建第二份码表"，T-13/T-16 亦不得自造。**日后要加，先回 §5.4-4 改口径再动代码。**
- **消费纪律（A-37 §五-24 原句落进条款）**：T-13/T-16 消费时以 `@tm/shared/constants` 现值为准，**组件内禁字面量**；PRD 与 UI 文案表都不写死第二份数字。
