## 任务 2：手撕 4 题限时马拉松（约 120 分钟）

四题按顺序做，**每题 20 分钟写 + 5 分钟跑自检 + 5 分钟记录**（合计 30 分钟一题，四题 120 分钟）：

1. **T1 缩放点积注意力（含因果 mask + 多头）**。自检：`Q@K.t()/sqrt(d)` 的除法在 softmax **之前**；mask 在 softmax 之前填 `-inf`；头的切分是 `(B,T,C)→(B,h,T,dh)` 而不是任意 reshape；最后合并回 `(B,T,C)`。
2. **T2 DPO 损失**。自检：参考模型 logprob 在 `torch.no_grad()` 里算且不进梯度；序列 logprob 是 **token 求和且只在 assistant/非 -100 位置上**；β 乘在整个 log-ratio 外面；chosen/rejected 长度不同不能取 mean。
3. **T3 LoRA 层 forward + merge**。自检：`B` 零初始化、`A` 随机；scaling = `alpha/r`；旁路是 `x@A.t()@B.t()`（转置方向别写反）；merge 只加进 `base.weight`，bias 不动；merge 后 `forward` 不再走旁路。
4. **T4 AdamW 单步（或 GRPO 组内优势，二选一）**。AdamW 自检：偏差修正用 `1-b^t`；`eps` 在 `sqrt(v_hat)` **之外**加（PyTorch 约定）；权重衰减是 `p -= lr*wd*p` 的解耦形式。GRPO 自检：按组求均值/标准差、`std=0` 的组整组丢弃、优势形状与 rewards 同形。

T2 的自检脚本（另外三题照这个写法自己补，断言不许抄）：

```python
# dpo_check.py —— 用一个 2 token 的玩具样本对拍手写的 policy/reference 序列 logprob
import math, torch, torch.nn.functional as F

torch.manual_seed(0)
beta = 0.1
pi_c  = torch.tensor([-0.8, -1.1])          # 策略模型在 chosen 上各 token 的 logπ
pi_r  = torch.tensor([-1.5, -0.9])
ref_c = torch.tensor([-0.9, -1.0])          # 参考模型：no_grad 里算好的常量
ref_r = torch.tensor([-1.2, -1.3])

def dpo_loss(pc, pr, rc, rr, beta):
    pl = pc.sum() - pr.sum()                 # 序列级：token 求和（不是 mean）
    rl = rc.sum() - rr.sum()
    return -F.logsigmoid(beta * (pl - rl))

loss = dpo_loss(pi_c, pi_r, ref_c, ref_r, beta)
pl, rl = float(pi_c.sum() - pi_r.sum()), float(ref_c.sum() - ref_r.sum())   # 0.5 与 0.6
manual = -math.log(1.0 / (1.0 + math.exp(-beta * (pl - rl))))               # -logsigmoid
assert abs(loss.item() - manual) < 1e-6
assert abs(loss.item() - math.log(2)) < 0.01, f"相对偏好几乎没变时损失应在 ln2 附近: {loss.item()}"
print("DPO CHECK OK")
```

**完成判据**：四题各自 **≤20 分钟**从空文件写到自检打印（`DPO CHECK OK` 等），每题调试次数 ≤2；一题超时就在 `gaps.md` 记"第 X 题超时 N 分钟 + 卡在哪一步"；马拉松结果表贴进 `week15` 沿用的 `mlcoding/log.md`（题目 / 限时 / 是否独立写完 / 自检是否通过）。

> 注：为什么卡 20 分钟。真实手撕环节通常给 15-25 分钟，而且**没有 IDE 补全、不能跑 pip 装东西**。练 20 分钟不是让你快，是让你在时间压力下保留两样东西：先写形状注释、写完先跑最小自检。练熟了你会发现，超时的那 5 分钟永远花在"忘了转置"这种可预防的错误上。

## 三、常见问题与纪律

- **还没毕业/身份不确定怎么办？** 先按在校走暑期提前批（这是主路径），同时把 Day 4 任务 4 的社招补强单当作**备选分支**放着，1 月不启动就一分钱不花。**别为不确定的分支把主线拖住**。
- **拿到面试就停课准备面试？** 不要。1 月起主线仍是"每天 3 题 + 1 题手撕"，面试当天才减量（保算法手感 + 复述 `talk-open.md`）。停下来准备单场面试的代价是三周后手感归零。
- **无 Offer 怎么办？** 这是**已排期的分支而不是失败**：横移投数据构造 / 评测 / Agent 后训练岗（重叠约 80%、竞争小得多），简历首屏换成 Day 4 写的那两版；进大厂再转组是常规路径。**唯一要避免的是因为没 Offer 就重跑实验**——那既花钱又讲不出新东西。
- **单点卡多久放手？** 刷题按限时（10-35 分钟）；手撕一题 20 分钟到点就停，写"卡在哪一步"；非刷题卡点 40 分钟无解就写 NOTES + gaps。**资产链接修不好**就用手机流量 + 无痕窗口重试一次，再不行降级为"过程"。
- **卡时与钱**：本周上限 4h、预估 ¥6-10、默认 0。开卡前 `COST.md` 写清"跑什么、几小时、支撑哪条对外结论"；跑完即关机并确认"已关机"；**任何时候不点销毁**（销毁连数据盘一起清空）。
- **数字纪律（收口周最重要的一条）**：对外材料里每个数字要要么指向 `ASSETS-16WEEKS.md` 里一行可展示资产，要么写成"量级/约/未量化"。**总表里"点开验证失败"的行，它支撑的数字也一起撤**——一条打不开的链接，比没有链接更伤。
- **AI 工具的边界**：允许它解释报错、review 代码、把口播稿改顺、帮你列反问的措辞；**不允许**替你 AC 题、替你写项目经历与行为面故事、替你答追问。1-3 月你要在没有任何外援的会议室里，把 M2/M3/M4 讲成能被追问五层的东西。
