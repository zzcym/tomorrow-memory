## 任务 2：手撕 ML #2 —— DPO loss（约 70 分钟）

新建 `mlcoding/dpo_loss.py`：

1. 手写 `dpo_loss(policy_chosen_logps, policy_rejected_logps, ref_chosen_logps, ref_rejected_logps, beta=0.1)`，返回 `(loss, rewards_chosen, rewards_rejected)`；**用 `-F.logsigmoid` 而不是 `torch.log(torch.sigmoid(x))`**（数值稳定，这是必考点）。
2. 梯度 sanity：全 0 的 logits 差 → loss 应等于 `ln 2 ≈ 0.6931`。
3. **与 TRL 对拍**（这是今天的硬判据）：造一个 4 条偏好对的小 batch，用同一份 `ref` logprob，分别用你的函数与 TRL `DPOTrainer` 的 `odds_ratio_loss`（或当前版本的对应内部函数）算，**绝对差 < 1e-4**。

```python
import torch, torch.nn.functional as F

def dpo_loss(pc, pr, rc, rr, beta=0.1):
    logs = beta * ((pc - rc) - (pr - rr))
    loss = -F.logsigmoid(logs).mean()
    return loss, (beta * (pc - rc)).detach(), (beta * (pr - rr)).detach()

t = torch.tensor(0.0)
assert abs(dpo_loss(t, t, t, t, 0.1)[0].item() - 0.6931471805599453) < 1e-6
print("DPO SANITY OK")
```

**完成判据**：打印 `DPO SANITY OK`；对拍脚本打印 `DPO CROSSCHECK OK (diff=<一个具体数>)`，**diff < 1e-4**；能默写 `L_DPO` 的完整式子（含 `π_θ` 与 `π_ref` 四项）。

> 注：对拍时最容易对不上的三处：① TRL 默认按 **token 级 logprob 求和**（不是平均），你要保证自己也是求和；② `loss_type` 默认 `sigmoid`（标准 DPO），别配成 `ipo/orpo`；③ mask：`rejected` 里 padding 的位置没屏蔽。**diff 卡在 1e-2 级别基本都是这三条之一**，别去怀疑公式。

## 三、常见问题与纪律

- **"投了没回复"怎么办？** 这是常态，不是信号。**唯一正确的反应是继续按日计划走**（刷题 + 八股 + 下一批投递），同时把每次被拒的岗位名与 JD 关键词记进 `targets.md`——连续三家因为同一个要求拒你，那才是信号（多半是分布式/论文，处理办法见总计划风险 3：横移投数据构造、评测、Agent 后训练岗，技能重叠约八成、竞争小得多）。**不许**因为没回复就停下来改简历第 8 版或重跑实验：那是最舒服的拖延方式。
- **某天没完成怎么办？** 按"天-任务号"记进 `gaps.md`，Day 7 就是缓冲。**永远优先保 Day 4 的简历终版和 Day 5 的首批投递**——它们有外部时间窗（提前批在 2027 年 2-3 月开抢，但日常实习现在就在招），而题目下周还能刷。
- **刷题要不要按标签刷完再换？** 不要。Hot 100 本身就是按标签分组的，照它走；但每天最后一题**从上一个标签的队列里抽**（本周的链表题里夹一道昨天的滑窗），交错练习才留得住。
- **卡时与花费**：本周上限 4h、**默认 0h**。你大概不会需要用卡。真要用：先写清跑什么、多少钱、进简历哪一条；超预算就把那个数字删掉。跑完立刻关机（**不是销毁**），在 `COST.md` 回填真实值。
- **手撕 ML 的判据为什么比刷题严**（要"对拍通过"）：因为面试官看的是**你对自己代码的信任来源**。写出来 + 对拍通过 + 说清数值容差为什么这么定，三件事一起做才叫会手撕。只写出来不算。
- **AI 工具的使用边界**（求职周版本）：允许——面经检索、把报错解释给你、模拟面时当面试官出题、review 你写完的简历话术。**不允许**——替你刷题（你 AC 的每题都要能讲）、替你写手撕实现（对拍脚本可以问，实现不行）、替你回答"你项目难点是什么"（那是你最不该假手于人的 60 秒）。
- **节奏**：周一到周六每天 6-6.5h、周日 4h。**固定"上午刷题、下午八股与求职动作"的顺序**——刷体力题在前是因为它要求清醒，八股与投递允许在状态差时做。这个顺序一旦定下来，四周都别改。
- **最后一句**：你的技术故事比大多数同期候选人完整，短板在"手速 + 表达 + 运气"。手速和表达这四周能练，运气靠投递量。**别把运气的问题留给自我怀疑去解决。**
