## 一、5 条原始诉求逐条判定

### 诉求 1:语音 —— **达成**
- **说话键唯一且在界面中间下方**:`index.html:148` 底栏中央凸起 `.nav-mic`,`style.css:1035` 居中样式;三态(待命/录音/识别中)齐全。
- **无"解析"按钮**:语音结果回调直接自动解析(`app.js:699-708` onVoiceResult → doParse → 确认卡),全链路零多余点击。文字兜底卡里的"解析添加"是打字路径的提交键,不属违规(R1 已裁定)。
- **死胡同已消除**(重点核对,逐级降级全部落地):
  - 系统识别不可用(isRecognitionAvailable=false):有云端配置自动转云端,否则回调 `'unavailable'` → 文字兜底(`MainActivity.java:294-302`、`504-514`);
  - 麦克风权限拒绝:deny 分支直接回调 `'unavailable'` → 文字兜底,浮层不再卡"正在听"(`MainActivity.java:84-96`,R1 B2 已修);
  - 系统识别连续失败 2 次:自动记住、后续默认走云端,设置页有状态行 + "恢复系统语音优先"重置(`app.js:713-718`、`1002-1007`、`1047-1051`);
  - 云端录音 60 秒上限自动收尾、失败/超时一律落文字兜底(`app.js:691-696`、`R2 B13`);
  - 全代码无"没有可用的语音识别服务"死文案;任何错误最终都落到"可以直接打字,或用输入法的语音输入"的半屏输入卡,且带"重试语音"入口(`app.js:666-672`、`index.html:244-256`)。
- 取消语音会话令牌防迟到回调劫持(N1 已修,`app.js:628/632/685/701/711`)。

### 诉求 2:时间轴 —— **达成**
- **0-24 点轴 + 可 12h**:日视图 0–23 刻度(`app.js:237-246`);外观抽屉 24h/12h 切换,刻度与事件时间同步重绘(`app.js:230-247` hourFmtCache 强制重建,R1 B8/O1 已修),12h 中文时段(凌晨12/上午/中午/下午/晚上)。
- **按天/按周、右上角切换**:顶栏右侧 日/周 seg(`index.html:17-20`);周视图有 ‹/› 翻周 + "今天"快返(R1 B4 已修,`app.js:365-368`)。
- **切换按钮在屏幕下方**:页面切换全部在底部导航(日程/🎤/设置,`index.html:144-152`);设置页点日/周也能正确跳回(R1 B24 已修)。
- 附加核心体验均已在:当前时间红线 30 秒刷新(`app.js:348`)、打开定位到当前时刻前 1.5h、空档点击新建预填、跨天事件进全天条不进轴(core.js crossDayEnds + 视图层 `app.js:263-289` + 原生 Occ.java 同步,N3/N5 已修)、重叠封顶 3 列(core.js layoutColumns 有单测)。

### 诉求 3:课程表截图导入 —— **达成**
- **入口**:右上角 ⋮ 图标按钮(无文字,`index.html:21`)→ 图标菜单 → 导入课程表,符合"图标菜单"要求。
- **丢给 AI 一张截图 → AI 输出格式 → app 解析加入日程**:选图 → 视觉模型(`MainActivity.analyzeImage`,返回 `{"raw":纯JSON}`,非法 JSON 自动带强化提示重试 1 次)→ JS 解包 + 宽容归一化(`app.js:840-846` + core.js normalizeCourses,R1 P0 B1 已修,mock 已改同构返回)→ 预览页逐条可改/可勾选/学期锚点可调 → 重导自动替换旧课表事件且手写日程保留(`app.js:925-945`)→ toast 确认。模型错误原文展示不吞(R1 B7 已修)。
- 偏离记录:PRD §4 的"节次(period)+ 作息表"契约未按原样实现,改为 prompt 让 AI 直接输出具体时间(内置节次→时间换算规则)。链路自洽、用户可逐条改时间,判定为**可接受的契约偏离**,划入后续清单(见 §三)。

### 诉求 4:日间/夜间色调 + 自定义背景图,默认白 —— **达成**

- **同包名 + 同签名**(keystore.jks 保留于仓库,README 已注明签名变更才会丢数据):覆盖安装不清 `/data/data`,events.json / settings.json / meta.json 原地保留;`allowBackup=true` 兜底。
- **旧 events.json(无 recur/source 字段)**:
  - 展开层把"无 recur"事件按一次性日程处理(JS core.js:66-79 / Java Occ.java:59-77 双侧一致,有单测锚定),旧日程正常上时间轴、正常提醒;
  - 无 `source` 的事件不会被"重导课表替换"误删(`app.js:933` 按 `source==='timetable'` 过滤);
  - v1 旧提醒标记字段 `remindedAt` 显式兼容(Scheduler.java:77-82、AlarmReceiver.java:46-49),升级后不会重复提醒。
- **旧 settings.json(v1 的 llm/reminder 字段)**:
  - Java `saveSettings` 浅合并(逐键递归)在现有文件上打补丁,v1 的 llm / reminder 键不会被新键覆盖或丢弃(MainActivity.java:128-139、662-681);
  - JS 侧对 llm/vision/asr/appearance/school 逐字段取默认值补齐(app.js:97-103 + loadSettingsTab),v1 用户打开设置页即看到已填的 API 配置,新增的视觉/转写/外观项为空默认,保存不丢旧值。
- 残余小风险(可接受):若 v1 提前量键名与 `reminder.defaultLeadMinutes` 不一致,会回落默认 60 分钟——属参数降级,不丢数据不崩溃。
