# 明日日程 v2.2 · 安卓版 📱

时间轴日程 app:0-24 点日/周视图、一句话/语音记日程(大模型解析)、课程表文本导入、准时提醒 + 每晚「明日日程」汇总、三种桌面小组件、日/夜双主题。

**安装包:`明日日程.apk`**(Android 8.0+,已签名,覆盖安装旧版数据保留)

## v2 一览

| 功能 | 说明 |
|---|---|
| 🕐 时间轴主视图 | 0-24 点纵向时间轴,当前时刻红线每 30s 刷新,点空档直接新建;右上角「日/周」切换,周视图带教学周数 |
| 🎤 一个说话键 | 底栏中央凸起说话键,说完自动解析、可编辑确认、可撤销。识别链路自动降级:系统语音识别 → 云端转写(可选配置)→ 文字+输入法语音兜底,永不出现"没有语音服务"死胡同 |
| 📚 课程表导入 | 右上角 ⋮ 菜单 → 导入课程表:直接选课程表 app(WakeUp/小爱课程表等)导出分享的 <b>.ics 文件</b>,自动识别周次/单双周/停课周(EXDATE);也支持粘贴 JSON 或「周一 08:00-09:40 课程名」行文本;重导自动替换旧课表 |
| 🌗 日/夜主题 | 默认纯白日间,夜间/跟随系统一键切换;支持自定义背景图(自动加遮罩保证可读) |
| 💾 数据管理 | 设置页:LLM 连通测试、导出备份(下载/明日日程/)、导入备份(覆盖前二次确认)、清空日程 |
| 🧩 桌面小组件 | 2×2(下一条)/ 4×2(今日 3 条)/ 4×4(今日全览),装好即有内容,随事件变更与每日 00:05 自动刷新(30 分钟兜底),跟随系统深浅色;设置页有排查指引 |
| ⏰ 准时提醒 | AlarmManager 精确闹钟,默认提前 60 分钟(全局可改、单条可覆盖),通知点击直达当天 |
| 🌙 每晚汇总 | 每天 21:30(可改)推送「明日日程」卡片式通知 |
| 🔒 隐私 | 日程和 API Key 只存手机本地;联网仅访问你自己配置的接口 |

## 安装

1. 把 `明日日程.apk` 传到手机安装,首次允许"未知来源"
2. 「设置」→ 配置大模型 API(推荐 DeepSeek:Base URL `https://api.deepseek.com`,模型 `deepseek-chat`)
3. 可选:配「语音识别」云端转写(如 SiliconFlow 的 SenseVoice),系统语音识别不可用时自动顶上
4. 说话试试:「明天晚上八点和小王吃饭,在三里屯」;课程表:截图发给任意 AI → ⋮菜单 → 导入课程表 → 粘贴 AI 输出

> 💡 国产手机请到系统设置给本 app 开「自启动」并关闭电池优化;Android 12+ 首次弹「闹钟和提醒」授权,授权后提醒才准点。

## 重新构建

工具链(一次性,官方源):JDK 17 + Android cmdline-tools + `platforms;android-34` + `build-tools;34.0.0`(本机已装在 `E:\android-build\`)

```bash
node tests/core.test.mjs     # 逻辑单测(63 项)
bash build-apk.sh            # aapt2 → javac → d8 → 组装 → zipalign → apksigner
```

无 Gradle/AGP/androidx 依赖,APK 约 105KB。**升级安装保留 `keystore.jks`**(签名变了需卸载重装)。

## 诚实边界

- 提醒依赖系统闹钟:被厂商"一键清理"不影响闹钟,但极激进省电策略可能延迟;建议加白名单
- 手机关机错过提醒/汇总不补发;语音质量取决于所选链路(系统引擎/云端转写/输入法)
- 课程表识别在 app 外完成(任意 AI app),app 只解析粘贴的文本;支持 JSON 或「周几 时间 课程 教室 周次」行格式
- 小组件内容为今日日程,跨天事件以"全天"条目呈现
